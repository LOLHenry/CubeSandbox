# Android 沙箱渲染：按需高帧率（材料稿）

## 标题

Android 沙箱：AI Agent 基础设施之一，诉求按需高帧率渲染

## 场景诉求

**按需高帧率渲染：** GUI Agent 在沙箱中「截图 → 决策 → 交互」，需在截图时高帧率出帧，非截图时按需减少渲染空转，进而提升密度、减少单步等待。

## 业务问题

**1. 非截图阶段渲染空转：** Agent 交互为「截图 → 决策 → 交互」，仅截图需要画面；非截图阶段若仍持续渲染，挤占算力、限制单机并发。

**2. 截图阶段出帧慢：** 截图须尽快得到稳定画面；复杂界面软件渲染 CPU 占用可超过 50%，部分场景帧率低于 10fps，出帧慢则单步等待变长。

## 技术诉求

**按需高帧率渲染**

**1. 按需渲染：** 非截图阶段减少无效合成，降低 CPU 占用，提升单机并发。控制策略须验证，避免拖慢「动作 → 稳定截图」。

**2. 快速渲染：** 需要出帧时尽快完成合成；同等部署密度下，通过多线程与算子优化提升软渲染出帧速度。
