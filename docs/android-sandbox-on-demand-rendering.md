# Android 沙箱渲染：按需高帧率（材料稿）

## 标题

Android 沙箱：AI Agent 基础设施之一，诉求按需高帧率渲染

## 场景诉求

**按需高帧率渲染：** Mobile GUI Agent 训练需大量沙箱并发，软件渲染 CPU 占用过半；截图时部分场景帧率偏低。

## 业务问题

**1. 按需：** Agent 交互为「截图 → 决策 → 交互」，仅截图需要画面；决策期持续合成无观测收益，占用 CPU，限制单机并发。

**2. 流畅：** 复杂界面软件渲染 CPU 占用可超过 50%，部分场景帧率低于 10fps；出帧慢则单步等待变长，CPU 占用同时限制单机并发。

## 技术诉求

**按需高帧率渲染**

**1. 按需：** 非截图阶段减少无效合成，降低 CPU 占用，提升单机并发。控制策略须验证，避免拖慢「动作 → 稳定截图」。

**2. 流畅：** 同等部署密度下，通过多线程与算子优化提升软渲染出帧速度。
